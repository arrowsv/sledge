# Installation

Download the latest release from the [releases page](https://github.com/arrowsv/sledge/releases/latest) by selecting the `Sledge.<ver>.zip` file.

Extract the zip file into the root folder of Red Faction: Guerrilla Re-Mars-tered. The structure should be follows:

```
📁 Red Faction Guerrilla Re-Mars-tered/
├── 📁 sledge/
│   ├── 📁 mods
│   ├── 📄 launcher.exe
│   └── 📄 sledge.dll
├── 📄 dinput8.dll
└── 📄 rfg.exe
```

Sledge's files can also be placed alongside `rfg.exe` in the root folder:

```
📁 Red Faction Guerrilla Re-Mars-tered/
├── 📁 mods
├── 📄 launcher.exe
├── 📄 sledge.dll
├── 📄 dinput8.dll
└── 📄 rfg.exe
```
