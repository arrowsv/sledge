## Checking logs

Use [`sledge.log`](../../api/lua/namespaces.sledge.md#log), [`sledge.log_warn`](../../api/lua/namespaces.sledge.md#log_warn), and [`sledge.log_error`](../../api/lua/namespaces.sledge.md#log_error) to write variable states or text to the `sledge.log` file.

## Reloading mods in-game

Click `Reload mods` in the `Sledge` menu to clear and re-run all active mod scripts.

!!! warning

    Reloading is useful for testing windows and widgets without restarting the game. However, it does not undo previous game modifications or file edits. Restart the game completely to fully test a mod.
