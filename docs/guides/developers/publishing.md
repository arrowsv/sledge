1. Set the `api_version` field in your `mod.toml` to the latest API version you tested against.

2. Compress your mod's folder into a `.zip` file structured like this:

    ```text
    📦 my_name.my_mod.zip
    └── 📁 my_name.my_mod/
        ├── 📄 mod.toml
        └── 📄 mod.lua
    ```

3. Upload the `.zip` file to the `Mods - Remaster (Sledge)` category on [FactionFiles](https://www.factionfiles.com/ff.php?action=files&file_category=52) (an account is required).
