Before publishing, set the `api_version` field in your mod's metadata to the latest API version you tested on.

Compress the mod's folder into a `.zip` file with the following structure:

```text
📦 my_name.my_mod.zip
└── 📁 my_name.my_mod/
    ├── 📄 mod.toml
    └── 📄 mod.lua
```

Upload the `.zip` file to the `Mods - Remaster (Sledge)` category on [FactionFiles](https://www.factionfiles.com/ff.php?action=files&file_category=52). An account is required to upload files.
