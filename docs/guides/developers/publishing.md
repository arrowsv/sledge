When you are ready to publish a mod, compress it into a `.zip` file with the following structure:

```text
📦 my_name.my_mod.zip
└── 📁 my_name.my_mod/
    ├── 📄 mod.toml
    └── 📄 mod.lua
```

Upload the `.zip` file to the `Mods - Remaster (Sledge)` category on [FactionFiles](https://www.factionfiles.com/ff.php?action=files&file_category=52). An account is required to upload files.
