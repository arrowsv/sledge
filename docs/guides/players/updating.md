2. Replace your old files with the new ones, keeping the exact same folder structure you chose during initial installation.

## Mods

Mods built for older versions can break after updating if underlying features change. After updating Sledge, always check for newer versions of your installed mods on FactionFiles. See how to [update a mod](managing-mods.md#configure-update-and-remove).
