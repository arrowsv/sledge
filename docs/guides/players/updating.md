To update Sledge, download the latest version from the [releases page](https://github.com/arrowsv/sledge/releases/latest) by selecting the `Sledge.<ver>.zip` file, then replace the old files with the new one. Ensure it is placed in the same file structure you chose when [installing Sledge](installing-sledge.md).

## Updating mods

Mods that were created for an older version may cause errors or not behave as intended if functionality they use is removed or changed by Sledge. After updating, always check if a newer version of the mod exists. See how to [update a mod](managing-mods.md#update-a-mod) for more information.
