Run `launcher.exe` to manage mods, change settings, and launch the game.

## Launcher

### Changing options

Click `Options` to show the options window. The main option to note is `Overlay key` (defaults to `F1`), which opens the in-game overlay.

Click `Apply` to save changes.

### Toggling and configuring mods

1. Click `Mods` to open the mod manager.
2. Check or uncheck a mod to enable/disable it.
3. Click a mod's name to view details and configure its options.
4. Click `Apply` to save changes.

If you added/removed folders while the launcher is open, click `Rescan`.

To browse for mods compatible with Sledge, click `FactionFiles`.

### Launching the game

Click `Play` to start the game. Switch the `Profile` dropdown to `Vanilla` if you want to run without Sledge.

!!! info "Running without the launcher"

    Sledge loads automatically whenever the game starts. To force a completely vanilla start without opening the launcher, add the `--vanilla` argument to the executable.

## In-game overlay

Press your `Overlay key` to toggle the overlay, which will free your mouse cursor.

- **Windows** - Toggle windows via the `Windows` menu. Drag title bars to move them or resize via the edges.
- **Widgets** - Toggle widgets via the `Widgets` menu. They will remain on-screen even when the overlay is disabled.
- **Reloading mods** - Developers can use the `Reload mods` option via the `Sledge` menu to refresh scripts. As a regular player, do not use this as it can have undefined results.
